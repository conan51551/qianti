# 小错题家

儿童错题归纳与练习生成小程序的首版准备包。

## 首版目标

- 家长或孩子拍照/上传错题，录入题目、答案和年级学科。
- AI 识别题目并提取知识点、错误类型和讲解。
- 按知识点查看错题本，支持再次练习和掌握度记录。
- 根据错题生成相似题、变式题，并提供答案与解析。

## 建议技术方案

- 客户端：微信小程序原生 TypeScript（后续可迁移 uni-app）。
- API：微信云函数。
- 数据库：微信云数据库 `mistakes` 集合。
- 文件：微信云存储；客户端只保存云文件 ID。
- AI：云函数统一适配 OpenAI 兼容接口，客户端永不保存 API Key。

## 目录

- `docs/PRD.md`：产品需求和验收标准
- `docs/AI接入方案.md`：免费/低成本模型接入和降级策略
- `docs/数据模型.md`：数据库实体与接口草案
- `docs/开发计划.md`：分阶段任务清单
- `apps/api/.env.example`：服务端环境变量模板
- `packages/ai/`：AI 结构化输出约定和提示词模板
- `miniprogram/`：微信小程序客户端
- `cloudfunctions/`：云函数

## 开始开发前需要确定

1. 在微信开发者工具创建云环境，并把 `app.js` 中的环境 ID 替换掉。
2. 是否需要账号登录、家长端和多孩子管理。
3. 首版是否支持拍照 OCR，还是先手动录入。
4. 模型服务的部署位置，以及是否接受图片上传到第三方模型服务。

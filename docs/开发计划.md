# 开发计划

## 第 1 阶段：可用闭环

- 建立小程序壳和 API 服务。
- 手动录入错题、列表、详情、删除。
- SQLite/Prisma 数据库和本地文件上传。

## 第 2 阶段：AI 分析

- 接入统一 AI Provider。
- 加入结构化输出校验、重试、超时和降级。
- 增加知识点、错误类型、讲解和复习建议。

## 第 3 阶段：智能练习

- 根据错题生成相似题/变式题。
- 记录作答，计算掌握度。
- 增加家长查看和复习提醒。

## 第 4 阶段：上线准备

- 微信登录、隐私协议、儿童数据删除。
- 图片存储、限流、日志、费用上限。
- 真机测试和小范围试用。

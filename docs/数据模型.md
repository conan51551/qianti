# 数据模型与 API 草案

## 实体

`Child(id, name, grade, createdAt)`

`Mistake(_id, openid, childId?, subject, grade, questionText, imageFileId?, userAnswer?, correctAnswer?, knowledgePoints[], errorType?, explanation?, mastery, source, createdAt)`

首版直接使用微信云数据库 `mistakes` 集合，所有查询都由云函数按 `openid` 隔离。

`Practice(id, mistakeId, questionText, answer, explanation, difficulty, createdAt)`

`PracticeAttempt(id, practiceId, userAnswer, isCorrect, createdAt)`

## API

- `POST /api/mistakes`：创建错题并触发分析
- `GET /api/mistakes?childId=&subject=&mastery=`：错题列表
- `GET /api/mistakes/:id`：错题详情
- `POST /api/mistakes/:id/practice`：生成一道变式题
- `POST /api/practices/:id/attempts`：提交练习答案
- `DELETE /api/mistakes/:id`：删除错题及关联图片

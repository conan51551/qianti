# 小错题家 — 产品介绍与讲解指南

> 本文档用于向他人介绍「小错题家」微信小程序时的参考话术与演示流程。

---

## 一、一句话介绍（电梯演讲）

「小错题家」是一款面向小学家庭的** AI 错题管理与练习 **微信小程序。家长或孩子拍照上传错题，AI 自动识别题目、提取知识点、分析错因，并生成相似变式题供针对性练习，配合四档掌握度追踪，帮孩子把每一道错题真正吃透。

---

## 二、解决什么问题

| 痛点 | 传统方式 | 小错题家的方案 |
|------|---------|---------------|
| 错题记录慢 | 手动抄题、手写错题本 | 拍照上传，AI 自动识别题目文字 |
| 不知道错在哪 | 只知道答案错了，不懂错因 | AI 多模态分析：错因 + 知识点 + 讲解 |
| 练习没针对性 | 刷题海、重复做已掌握的题 | 基于原题 AI 生成变式题，精准练习 |
| 不知道学会了没 | 凭感觉，没有量化 | 四档掌握度追踪：未练习→练习中→较熟悉→已掌握 |
| 知识点碎片化 | 错题散落，看不出薄弱模块 | 知识大纲页按知识点归类汇总 |

## 三、核心功能演示流程

建议按以下顺序演示（对应小程序页面流转）：

### Step 1：首页（错题总览）

**演示动作：** 打开小程序，展示首页。

**讲解要点：**
- 顶部有「今日复习」横向卡片，自动筛选 3 天内掌握度低于「较熟悉」的错题，提醒孩子优先复习
- 中间是掌握度速览条：已掌握 / 较熟悉 / 练习中 / 未练习 各多少道，一目了然
- 下方错题卡片列表，每张卡片显示：题目摘要、学科标签、掌握度小圆点（4 种颜色对应 4 个等级）
- 顶部学科分段筛选器，可按数学/语文/英语快速筛选
- 如果有 AI 分析正在处理中，首页会每 4 秒自动轮询，分析完成后内容实时刷新，无需手动刷新

> **亮点话术：**「首页不是简单的错题列表，而是一个智能复习调度器——它知道哪些题该今天复习。」

### Step 2：新增错题（拍照录入）

**演示动作：** 点击底部 Tab「新增」。

**讲解要点：**
- 选择学科（数学/语文/英语）和年级（1-6 年级）
- 拍照或从相册选取错题图片，支持预览、替换、删除
- 可选填写题目文字、自己的答案、正确答案（不填也行，AI 能从图片识别）
- 点击保存后，错题进入云数据库，同时异步触发 AI 分析

> **亮点话术：**「拍照就行，题目文字不用手打——AI 能从图片里读出来。」

### Step 3：AI 分析（错题详情页）

**演示动作：** 点击首页任意一张错题卡片，进入错题详情页。

**讲解要点：**
- 展示 AI 分析结果：识别出的题目原文、错因类型、详细讲解、复习建议
- 知识点标签：AI 提取 1-5 个标准知识点，每个标注是核心考点还是辅助知识
- 掌握度进度条：当前等级 + 颜色标识
- 底部两个操作：开始练习 / 删除错题

> **亮点话术：**「AI 不只是告诉你答案错了，它拆解到知识点级别——这道题考的是'进位加法'，孩子需要补的是这个知识点，不是再多刷 10 道题。」

### Step 4：AI 变式题练习

**演示动作：** 在详情页点击「开始练习」，进入练习页。

**讲解要点：**
- AI 基于原错题的知识点和错因，生成一道相似但不同的新题
- 三阶段流程：加载中 → 答题 → 结果
- 孩子输入答案后提交，系统自动判对错（精确匹配，避免子串误判）
- 答对：掌握度 +1（上限已掌握）；答错：掌握度 -1（下限未练习）
- 结果页展示正确答案和详细解析

> **亮点话术：**「不是让孩子重做错题，而是出一道考查同一个知识点的新题——真正检验是否学会了。答对三次就算掌握，答错会降级，保证不是蒙对的。」

### Step 5：学习统计

**演示动作：** 返回首页，点击「统计」入口。

**讲解要点：**
- 总体掌握进度：已掌握错题占总数的百分比
- 四档分类统计：已掌握 / 较熟悉 / 练习中 / 未练习 各多少
- 分学科掌握度柱状图：每个学科的掌握百分比，颜色区分（绿=优秀/蓝=良好/橙=待提升）
- 练习数据：累计练习次数、正确率
- 待复习列表：掌握度低于「较熟悉」的错题，按最久未练习优先排序

> **亮点话术：**「家长打开统计页就能看到：数学掌握 72%，语文 45%——哪个学科薄弱一目了然，不用猜。」

### Step 6：知识大纲

**演示动作：** 返回首页，点击「知识大纲」入口。

**讲解要点：**
- 按知识点归类汇总所有错题
- 每个知识点显示关联的错题数量
- 点击知识点可查看相关错题

> **亮点话术：**「如果'退位减法'这个知识点关联了 5 道错题，说明这个模块需要系统复习——不是一道题的问题，是知识结构的问题。」

### Step 7：会员体系

**演示动作：** 进入「我的」页面，点击会员卡片。

**讲解要点：**

> **亮点话术：**
> - 「免费版就能用核心功能，5 次分析 + 3 次练习，足够体验价值。」
> - 「月度会员不到 20 块，一天不到 7 毛钱，比一本练习册便宜。」

## 四、技术架构亮点

如果听众关心技术实现，可以补充以下内容：

### 整体架构
```
微信小程序前端（原生 WXML/WXSS/JS）
        ↓
微信云开发（云函数 + 云数据库 + 云存储）
        ↓
AI 模型（OpenAI 兼容接口，多模态图文理解）
```

### 技术特点

| 特点 | 说明 |
|------|------|
| 纯云开发 | 无需自建服务器，11 个云函数承载全部业务逻辑 |
| 多模态 AI | 支持图片+文字混合输入，AI 同时做 OCR 识别 + 知识点提取 + 错因分析 |
| API Key 安全 | 密钥只存云函数环境变量，客户端永不接触密钥 |
| 降级策略 | AI 服务不可用时自动返回 FALLBACK 结构，不阻断流程 |
| 掌握度算法 | 答对 +1 / 答错 -1，四档递进，量化学习进度 |
| 自动轮询 | AI 分析异步处理，首页 4 秒轮询自动刷新结果 |
| 数据隔离 | 基于微信 OpenID 天然隔离，每个用户只能看自己的数据 |
| 设计规范 | 全量遵循 Apple HIG 设计系统，iOS 原生视觉体验 |

### 云函数清单（11 个）

| 函数名 | 职责 |
|--------|------|
| login | 初始化用户、创建数据集合 |
| addMistake | 录入错题，触发 AI 分析 |
| analyzeMistake | 多模态 AI 分析（图文） |
| listMistakes | 查询用户错题列表 |
| getMistake | 查询单条错题详情 |
| generateQuestion | AI 生成变式练习题 |

| deleteMistake | 删除错题 + 清理图片 |
| saveProfile | 保存孩子信息 |
| exportMistakes | 导出全部错题 JSON |

## 五、设计理念

1. **以掌握度为核心，而非题目数量**：不做题海，做精准复习
2. **AI 辅助而非替代**：AI 做分析、出题、判题，但学习决策权在家长和孩子
3. **极简操作**：拍照 → AI 分析 → 变式练习，三步闭环
4. **数据驱动**：所有学习行为可量化、可追溯、可导出
5. **Apple HIG 视觉**：inset grouped 列表、SF Pro 字体、iOS 系统色，给孩子和家长熟悉的好感

## 六、常见问题应答（Q&A 预案）

**Q：AI 分析准确吗？**
A：采用多模态 AI 模型，能同时理解图片和文字。系统提示词经过专门设计，要求输出结构化 JSON（知识点、错因、讲解、复习建议），并限制在 1-5 个标准知识点。AI 信心度（confidence）也会输出，家长可以参考。如果 AI 服务不可用，有降级策略不会崩溃。

**Q：和拍照搜题 App 有什么区别？**
A：拍照搜题是「给答案」，我们是「找错因 + 补漏洞」。搜题 App 解决的是「不会做」，我们解决的是「做错了为什么错、怎么不再错」。变式题练习确保不是背答案而是真学会。

**Q：数据安全吗？**
A：全量存储在微信云开发，基于 OpenID 天然隔离。不收集任何非错题相关数据。会员页有明确隐私声明。

**Q：支持哪些学科和年级？**
A：当前支持数学、语文、英语三个学科，1-6 年级。架构可扩展，后续可加科学等学科。

**Q：为什么用微信小程序而不是独立 App？**
A：小学生家长几乎人人有微信，小程序免安装、免下载，打开即用。微信云开发也免去了服务器运维成本，能以极低运营成本提供服务——这就是为什么月度会员只要 19.9 元。

**Q：商业模式可持续吗？**
A：核心成本是 AI 调用费用。免费版每月 5 次分析 + 3 次练习足够体验，重度用户自然会转付费。年度会员 ¥168 日均不到 5 毛钱，对标一本练习册的价格但提供个性化体验。
